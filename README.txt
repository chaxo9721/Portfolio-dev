PORTFOLIO FUTURISTE — GUIDE RAPIDE

FICHIERS
- index.html : contenu, textes, liens et projets
- style.css : design futuriste / responsive
- script.js : animations et année automatique
- mayana-logo.png : logo fourni

PERSONNALISATION
Dans index.html, recherche et remplace :
- TON NOM
- VOTRE VILLE
- votre@email.com
- les liens GitHub / LinkedIn / Instagram
- les noms et descriptions des projets
- les pourcentages des compétences

PHOTO
Pour mettre ta photo :
1. ajoute photo.jpg dans le même dossier ;
2. dans index.html, remplace le bloc .profile-placeholder par :
   <img src="photo.jpg" alt="Photo de TON NOM">

CV
Place ton fichier CV.pdf dans le même dossier. Les boutons de téléchargement fonctionneront automatiquement.

PROJETS
Les deux premiers visuels sont des maquettes créées en CSS.
Le troisième utilise le logo Mayana fourni.
Tu peux remplacer les blocs visuels par de vraies images :
<img src="images/mon-projet.jpg" alt="Mon projet">

LIENS
Remplace les liens "https://github.com/", "https://www.linkedin.com/" et
"https://www.instagram.com/" par tes profils.

LANCEMENT
Double-clique sur index.html ou utilise Live Server dans VS Code.
